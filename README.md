# AI Dream Note

夢を目標に変え、目標を今日の行動につなげる個人向けMVPアプリです。

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase optional
- Groq / Gemini / OpenAI provider structure

## Local Setup

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Environment Variables

Copy `.env.example` to `.env.local` and set only the keys you use.

Do not commit `.env.local`.

## Current Status

This is a personal-use MVP. Core flows are implemented:

- Dreams
- Goals
- Tasks
- Inbox
- Today actions
- Daily reflection
- AI dream clarification
- AI today action suggestions
- AI weekly review
