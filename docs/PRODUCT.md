# PRODUCT.md

## アプリの目的

AI夢ノートは、人生の夢・目標・日々の行動をつなげる個人向けアプリです。

目的は、夢をただ記録することではありません。
夢に期限をつけ、目標へ分解し、今日の行動へ落とし込み、日々の振り返りで継続できるようにすることです。

## ターゲットユーザー

現在の主なターゲットは、このアプリの制作者本人です。

想定する利用シーン:

- 朝に開いて、今日やることを確認する
- 思いついた夢や目標をその場で保存する
- タスクを4分類で整理する
- 夜に振り返りを書く
- 週次・月次で夢と行動のつながりを見直す

将来的には、人生設計や事業準備を自分で管理したい個人にも広げられる可能性があります。

## 解決する問題

多くの夢や目標は、書いた時点では気持ちが高まっていても、日々の行動につながらないまま忘れられます。

このアプリは次の問題を解決します。

- 夢と日々のタスクが分断される
- 長期目標が抽象的なまま残る
- 今日やるべきことの優先順位が分からない
- 緊急タスクに追われ、重要だが緊急ではない行動が後回しになる
- 振り返りが習慣化しない

## 提供価値

- 夢に期限を持たせられる
- 夢を目標、タスク、振り返りにつなげられる
- 「緊急ではないが重要」な行動を見失いにくくする
- 今日やることを固定件数ではなく、状況に応じて表示できる
- AIによる分解・優先順位付けに拡張しやすい

## 設計思想

このアプリはToDo管理だけに寄せないでください。

タスク管理は重要ですが、中心にあるのは「夢から逆算した行動」です。
タスクだけが増えるUIではなく、行動の理由や長期的な意味が分かるUIを目指します。

一方で、日常画面では夢や目標の情報を出しすぎないことも重要です。
毎日開く画面では「今日何をするか」を最短で理解できるようにします。

## 今日やることの基本思想

「今日やること」は、単に期限が近いタスクを表示する機能ではありません。

特に「緊急ではないが重要」な行動を後回しにしないことを重視します。
緊急タスクだけで一日が埋まらないようにし、可能な限り「未来を変える重要な行動」を含める設計を目指します。

今日の行動候補を決める際は、以下を考慮します。

- 緊急性
- 重要性
- 期限
- 関連する夢・目標
- 夢の実現への寄与度
- 最近その夢に向けた行動ができているか

将来的にAIで提案する場合も、期限順のタスク抽出に留めず、「今日この行動をする意味」が分かる提案にしてください。

## 成功条件

MVP時点の成功条件:

- 朝に今日やることを確認できる
- 夢を登録できる
- 夢に目標を紐づけられる
- タスクを夢・目標に紐づけられる
- タスクを4分類で見られる
- 夜に振り返りを残せる
- スマホでもPCでも破綻なく使える

将来的な成功条件:

- AIが夢を実行可能な計画に分解できる
- 今日やるべき行動の提案理由が分かる
- 継続利用によって夢・目標・行動の履歴が蓄積される
- 進捗の遅れや偏りに気づける
