# ROADMAP.md

このロードマップは、現在の実装状況を前提にした開発計画です。詳細な実装状況は `docs/FEATURES.md` を確認してください。

## Phase 1: 自分自身が毎日使えるMVP

目的:

AIなしでも、夢・目標・タスク・Inbox・振り返りを毎日使える状態にする。

現在できていること:

- ホーム画面
- 今日やること表示
- 夢の登録、編集、ステータス変更、保留
- 夢を6本の柱で整理
- 目標の登録、編集、アーカイブ
- タスクの登録、編集、完了、アーカイブ
- タスク4分類
- タスクと夢・目標の紐付け
- タスクの夢・目標紐付け整合性チェック
- Inboxの登録、編集、アーカイブ
- Inboxから夢・目標・タスクへの変換
- 日次振り返り
- localStorage保存
- Supabase用スキーマ
- Supabase保存失敗時の通知
- サーバー不要HTMLプレビュー
- スマホ幅とPC幅の基本レイアウト

Phase 1でまだ確認・改善したいこと:

- 実Supabaseプロジェクトでの接続確認
- スマホ実機幅での主要フロー確認
- アーカイブ済みデータの復元導線
- 完全削除を入れるかどうかの判断
- Next.jsのlockfile/SWC警告の整理
- npm audit警告への対応方針決定

Phase 1完了条件:

- 朝に開いて「今日やること」が分かる
- 夢、目標、タスク、Inboxを迷わず登録できる
- 登録済みデータを編集できる
- 不要になったデータを非表示にできる
- タスクを4分類で確認できる
- 夢や目標につながる第2領域の行動が今日やることに出る
- 振り返りを保存し、再表示できる
- 保存失敗時にユーザーが気づける

## Phase 2: 夢手帳の計画階層を整える

目的:

「夢を、今日の行動に変える。」ために、夢手帳としての5年、1年、月、週、今日の計画階層を整える。

候補機能:

- 5年計画
- 1年計画
- 月間計画
- 週間計画
- デイリー計画
- 未完了行動の転記
- 6本の柱ごとの偏り確認
- 今日の行動から将来の夢を考えるボトムアップ導線

注意:

- AIチャットを主役にしない
- UIを複雑にしない
- 今日やることは3件固定にしない
- 緊急タスクだけでなく、第2領域の重要行動を含める
- AIは紙では面倒な逆算、分類、転記先提案を補助する位置づけにする

## Phase 3: 振り返り・進捗分析

目的:

継続利用によって、夢と行動の履歴が見える状態にする。

候補機能:

- 週次レビュー
- 月次レビュー
- 夢ごとの進捗確認
- 完了タスク履歴
- 期限遅れ目標の検出
- 第2領域タスクの実行率表示
- AIによる振り返り要約
- 次週の重点行動提案

## Phase 4: 他ユーザーが利用できるサービス化

目的:

個人MVPから、他ユーザーも安心して使えるサービスへ拡張する。

候補機能:

- 本番向け認証フロー
- オンボーディング
- データバックアップ
- データエクスポート
- PWA化
- 通知
- 利用規約
- プライバシーポリシー
- 課金モデル検討
- スマホアプリ化検討

## 2026-07-23 追記: Phase 2 開始

Phase 2の最初の中核機能として、「夢をAIが具体化し、目標候補と最初の行動へ分解する機能」を実装した。

完了したこと:

- 夢からAI提案を生成
- JSON SchemaでAI出力構造を固定
- Groq / Gemini / OpenAIを切り替え可能なAI Provider構造
- Groq `openai/gpt-oss-20b` での実API 5ケース検証
- JSON/Schema異常時のみ最大1回リトライ
- Groq向けSchemaを寛容化し、アプリ側で既存Schema互換へ正規化
- AI提案をユーザー確認前に正式データへ保存しない
- 採用操作により夢、目標、タスクへ反映
- 最初の一歩をタスクとして登録
- AI提案履歴の保存基盤
- 今日やることAI
  - 既存の今日候補タスクから優先順と理由を生成
  - 緊急タスクと第2領域の重要行動を両方考慮
  - 手動生成と同日キャッシュで無料API枠を節約
  - 既存タスクはAIが勝手に変更しない
- 週次レビューAI
  - 今週の完了タスク、夢・目標への行動、日次振り返りを集計
  - 事実、気づき、来週の重点を短く表示
  - 放置されている夢、緊急偏り、第2領域実行状況を確認
  - 手動生成と同一週キャッシュで無料API枠を節約

次にPhase 2で進める候補:

1. AI提案履歴一覧と再表示
2. AI提案から目標・タスクへ採用した後の進捗確認
3. 週次レビューAIの実データ品質を継続検証
