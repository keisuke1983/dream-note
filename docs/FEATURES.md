# FEATURES.md

このドキュメントは、現在のコードベースを確認したうえで実装状況を整理するものです。理想仕様ではなく、現時点の実装事実を優先します。

## 使用技術

- Next.js 14.2.35
- React 18
- TypeScript
- Tailwind CSS
- Supabase JS
- PostgreSQL想定のSupabaseスキーマ
- localStorageによるローカル保存
- サーバー不要の静的HTMLプレビュー

## 主なファイル

- `app/page.tsx`: Next.js版のメインUI、状態管理、localStorage保存、Supabase保存
- `app/layout.tsx`: メタデータとルートレイアウト
- `app/globals.css`: Tailwindベースの共通スタイル
- `supabase/schema.sql`: Supabase/PostgreSQL用テーブルとRLSポリシー
- `outputs/ai-dream-note-preview.html`: サーバー不要で確認できるHTML版プレビュー
- `.env.example`: Supabase接続用環境変数とAI Provider用環境変数の例
